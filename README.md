Admin–Employee Task Management System is a modern web application built with React and Tailwind CSS, featuring an elegant UI and real-time dashboards. It enables Admins to create and assign tasks, while Employees can view and update their assigned work. The system supports role-based login, task tracking, and data persistence through Local Storage — providing a smooth, single-page task management experience.

🚀 Features

✅ Role-based authentication (Admin & Employee) ✅ Create and assign tasks dynamically ✅ Task status tracking (New, Active, Completed) ✅ Real-time dashboards for both Admin and Employee ✅ Data persistence using Local Storage ✅ Reset functionality to start fresh anytime ✅ Responsive UI built with Tailwind CSS ✅ Interactive and user-friendly design

🛠 Tech Stack Frontend: React.js Styling: Tailwind CSS State Management: React Context API Storage: Local Storage UI Library: Custom + Tailwind components
